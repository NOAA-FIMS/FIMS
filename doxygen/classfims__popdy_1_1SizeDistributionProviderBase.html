Detailed Description

template<typename Type>
class fims_popdy::SizeDistributionProviderBase< Type >

Base interface for objects that provide population-level size distributions.

Implementations of this interface prepare and expose pooled population-level size products on a biological size grid. The interface is intentionally separate from catch-at-age so other FIMS modules can consume size products without depending on CAA-specific logic.

Template Parameters
TypeNumeric type used for prepared size products.
