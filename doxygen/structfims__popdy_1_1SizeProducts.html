Detailed Description

template<typename Type>
struct fims_popdy::SizeProducts< Type >

Cached population-level size outputs on a biological size grid.

This container can be used by a size provider to store prepared size-related outputs for a pooled population, including mean length-at-age, spread-at-age, and age-to-size probabilities on the internal biological size grid.

Template Parameters
TypeNumeric type used for cached values.
