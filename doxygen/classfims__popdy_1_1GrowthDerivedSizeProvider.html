Detailed Description

template<typename Type>
class fims_popdy::GrowthDerivedSizeProvider< Type >

Size provider that converts growth outputs to population size products.

The provider reads mean length, length standard deviation, and weight-at-age from a Growth-derived observation object, then builds probability rows on the population biological size grid.

Template Parameters
TypeNumeric or automatic-differentiation scalar type.
