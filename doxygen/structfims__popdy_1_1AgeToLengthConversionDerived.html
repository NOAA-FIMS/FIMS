◆ PrepareForCurrentState()

template<typename Type >
virtual bool fims_popdy::AgeToLengthConversionDerived< Type >::PrepareForCurrentState ( )
inlineoverridevirtual

Ensures the linked growth products and population size-provider products are prepared for the current model state.

This helper reuses already prepared growth products when available and only triggers preparation when products have not yet been prepared. It then prepares the linked population size provider so the age-to-length conversion can read population age-to-size rows for mapping into fleet observation bins.

Returns
True if the required growth products are available for this age-to-length conversion path and the linked population size provider can be prepared.

Implements fims_popdy::AgeToLengthConversionBase< Type >.
