# FIMS estimates for the example data

Precomputed estimate tibbles returned by
[`get_estimates()`](https://NOAA-FIMS.github.io/FIMS/reference/get_FIMSFit.md)
for the example data, with and without optimization.

## Usage

``` r
estimates_big_optimized
```

## Format

A tibble returned by
[`get_estimates()`](https://NOAA-FIMS.github.io/FIMS/reference/get_FIMSFit.md).
