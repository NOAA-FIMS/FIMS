# FIMS fit using the example data

Precomputed
[FIMSFit](https://NOAA-FIMS.github.io/FIMS/reference/FIMSFit.md) objects
for the example data, with and without optimization. Both objects have
the same slots; the optimized fit includes uncertainty information when
available.

## Usage

``` r
fit_big_optimized
```

## Format

An object of class `FIMSFit`.
