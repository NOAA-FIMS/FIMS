# FIMS parameter tibble

A tibble of default FIMS parameters updated with operating-model values
for the example data set. The parameter table uses the same columns and
structure returned by
[`setup_default_parameters()`](https://NOAA-FIMS.github.io/FIMS/reference/setup_default_parameters.md).

## Usage

``` r
parameters_big
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 474
rows and 11 columns.
